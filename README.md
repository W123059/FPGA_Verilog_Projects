# FPGA-Verilog-Projects

作者：王志源|华南师范大学电子信息工程2025级

本仓库用于存放我本科阶段学习Verilog HDL设计与FPGA开发过程中完成的一些有挑战性和代表性的、通过仿真与上板验证的项目，作为科研入门的准备与积累

技能与工具：
硬件描述语言：Verilog HDL、SystemVerilog（学习中）
开发工具：Quartus Prime 20.1、Notepad++、ModelSim Altera、Visio等主要工具和PCtoLCD2002等辅助开发工具
FPGA平台：Altera Cyclone IV
其他：时序分析、Testbench 编写、波形仿真

工程：
1.key_filter（按键消抖）
2.beep（蜂鸣器演奏音符）
3.smg_static（数码管静态显示，全0到全9）
4.top_seg_595（借助595控制模块实现从0到999_999的数码管动态显示）
5.vga_char（使用vga协议实现汉字字符显示）
6.rs232（使用串口rs232实现PC机与FPGA的数据传递）
7.rs485（使用串口rs485实现两块FPGA板的相互控制）
......

目的：正在为研究生阶段从事 “FPGA 加速、数字系统设计、嵌入式系统” 等方向的研究做准备，希望加入课题组深入学习。
